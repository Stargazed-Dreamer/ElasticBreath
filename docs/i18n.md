# 国际化语言包指南

ElasticBreath 使用基于 JSON 文件的轻量国际化机制,支持多语言界面。本文档说明如何为项目添加新的语言包。

## 国际化机制说明

- 语言包文件位于 `ElasticBreath.App/i18n/` 目录下,均为 JSON 格式。
- 文件名即文化代码(culture code),例如 `zh-CN.json`、`en-US.json`、`ja-JP.json`。
- `LocalizationService` 在启动时自动发现该目录下所有 `*.json` 文件,并通过 `AvailableLanguages` 暴露可选语言列表。
- 当前选中的语言由 `settings.Language` 字段决定,持久化于可执行文件旁的 `config/settings.json` 中。
- 代码中通过 `T(key)` 查找文本,通过 `Tf(key, args)` 查找并填充带占位符的格式字符串。
- 缺失键不会抛异常,而是回退返回键名字符串本身(便于在 UI 上即时发现遗漏)。
- 不存在复数化引擎,具体处理方式见下文[占位符与复数](#占位符与复数)。

## 创建新语言包步骤

以新增日语 `ja-JP` 为例:

1. **复制模板**:从 `zh-CN.json` 或 `en-US.json` 复制一份,重命名为目标文化代码文件,例如 `ja-JP.json`。
   ```bash
   cp ElasticBreath.App/i18n/zh-CN.json ElasticBreath.App/i18n/ja-JP.json
   ```

2. **翻译全部值**:将文件中所有 **132** 个键对应的值翻译为目标语言。
   - **键名必须保持逐字节一致**,不得修改、增删或调整大小写。
   - 仅翻译值,不要改动键。

3. **确认编码**:保存为 **UTF-8 无 BOM**,换行符与项目其他文件一致(CRLF)。

4. **构建**:正常执行 `dotnet build ElasticBreath.sln`。语言包文件会通过 csproj 中的 Content glob(`i18n\*.json`)自动复制到输出目录,无需手动配置。

5. **选择语言**:启动应用后,在设置窗口的语言下拉框中选择新增的语言;选中后 `settings.Language` 会写入 `config/settings.json`,下次启动自动生效。

## 键命名约定

语言包采用**点分层级键名**,便于按模块归类。当前键空间划分为以下前缀:

| 前缀 | 用途 |
| --- | --- |
| `app.*` | 应用级名称、通用术语 |
| `state.*` | 状态机各状态(Idle/Working/Resting/Paused)相关文案 |
| `button.*` | 按钮文本 |
| `settings.*` | 设置窗口的字段、说明、单位 |
| `notify.*` | 通知与提示消息 |
| `pressure.*` | 水位/压力模型相关文案 |
| `transition.*` | 状态切换时的提示 |
| `probe.*` | 探针/检测相关文案 |
| `help.*` | 帮助窗口内容 |
| `about.*` | 关于窗口（版本/作者/仓库/许可证/简介与按钮文案） |
| `crash.*` | 崩溃恢复窗口 |

### 格式字符串与占位符

- 带参数的文案使用 `{0}`、`{1}` 等位置占位符,由 `Tf(key, args)` 按序填充。
- **翻译时不得调换占位符顺序**,否则会导致参数错位。例如 `notify.remaining` 形如 `"剩余 {0} 分钟"`,译文中 `{0}` 必须保留且语义对应。
- 不要在译文中新增或删除占位符,数量必须与源文件一致。

## 占位符与复数

本项目**没有复数化引擎**,不区分单复数形式。处理建议:

- 优先使用中性表述,例如"剩余时长"、"距离休息"。
- 对于必须给出数量的场景,使用简写形式,如 `5s`、`3m`,或直接以占位符填充数字。
- 现有 `en-US` 语言包即采用此策略,可作为参考。

## 验证清单

新增语言包后,请逐项确认:

- [ ] 全部 **132** 个键均存在,与 `zh-CN.json` / `en-US.json` 对称。
- [ ] 无重复键(JSON 解析时后者会覆盖前者,但应主动排查)。
- [ ] 文件为合法 JSON(可用编辑器或 `jq` 校验)。
- [ ] 每个含占位符的键,其占位符数量与源文件一致,顺序未变。
- [ ] `dotnet build ElasticBreath.sln` 通过,输出目录中包含新语言包文件。
- [ ] 启动应用,在设置中切换到新语言,逐项点检 UI 文案是否正确显示,无键名裸露。
